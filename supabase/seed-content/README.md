# Original development content

These three short original demo works were created for Shelf development. They contain no text from the commercial titles in the reference prototype. They may be used, copied and redistributed for this project's development/demo purposes; no real publisher or contributor relationship is represented.

The named Shelf Demo Studio is an explicitly fictional, unclaimed seed contributor, with reserved `.invalid` contact information. It has no Auth account, login or admin role. Demo licenses are operator-reviewed seed declarations, not evidence of rights to any future production catalogue.

Only JSON chapter files are uploaded to the private bucket by `npm run db:seed:storage`. They are never bundled into the frontend or placed in `/public`. Plain text is the content contract: the later uploader must validate JSON structure, byte limits and paragraph strings; the reader must render text, never HTML. MIME filtering alone is not content validation.
